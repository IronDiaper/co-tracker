# tests/data/

Видео для сквозных тестов. Короткие синтетические видео 256×256 для количественных
тестов (статика, сдвиг, окклюзия) сюда не сохраняются: тесты генерируют их в памяти
функциями из [`tests/synthetic.py`](../synthetic.py).

| Файл | Что это | Размер | Кадры | fps |
|---|---|---|---|---|
| `apple.mp4` | копия `assets/apple.mp4` из репозитория авторов (реальное видео) | 1296×720 | 50 | 10 |
| `shapes.mp4` | процедурный: статичный фон, 3 текстурных спрайта 64×64 (прямая, окружность, синусоида), спрайт A проходит за тёмным столбом | 480×272 | 30 | 12 |
| `shapes_gt.npz` | истинные треки для `shapes.mp4`: 64 точки (27 на спрайтах, 37 на фоне) | | | |
| `pan_zoom.mp4` | процедурный: «камера» над большой текстурой, сдвиг 4 и 1.5 px/кадр, зум до ×1.29, поворот до 6.6° | 480×272 | 30 | 12 |
| `pan_zoom_gt.npz` | истинные треки для `pan_zoom.mp4`: 40 точек сеткой 8×5 | | | |

Формат `*_gt.npz` совпадает с форматом входов и выходов `CoTrackerPredictor`:

- `queries` — `[N, 3]` float32, `(t, x, y)`, все запросы на кадре 0;
- `tracks` — `[T, N, 2]` float32, `(x, y)` в пикселях;
- `visibility` — `[T, N]` bool (точка закрыта другим слоем или вышла из кадра → `False`);
- `fps` — частота кадров.

## Как получены процедурные ролики

```bash
docker run --rm --network none -v "$(pwd)/tests:/app/tests" cotracker3:test python tests/synthetic.py
```

Генератор детерминирован (фиксированные seed), сжатие — H.264 `crf 15` встроенным в
`imageio-ffmpeg` ffmpeg. Истинная видимость считается по карте слоёв: точка видна, если
в её пикселе сверху лежит её же слой. Для `pan_zoom` деформация кадра делается через
`grid_sample(align_corners=True)`, поэтому соглашение о центрах пикселей точно такое же,
как у CoTracker.

Ручная проверка на этих файлах (`scaled_offline.pth`, CPU, 4 потока), по кадрам 1..T-1,
потому что на кадре 0 предиктор подставляет саму точку запроса:

| Ролик | PSNR сжатия | Средняя ошибка видимых точек | p95 | Точность видимости | Инференс |
|---|---|---|---|---|---|
| `shapes` | 29.1 дБ | 0.15 px | 0.39 px | 99.7% | 12.1 с |
| `pan_zoom` | 28.0 дБ | 0.21 px | 0.43 px | 99.8% | 10.9 с |
