# reference/

Эталонные результаты для теста `tests/test_reference.py`: треки CoTracker3 на
`tests/data/apple.mp4` (сетка 10×10, все 50 кадров), посчитанные в этом же
Docker-образе (`torch 2.4.1+cpu`, `scaled_offline.pth`).

| Файл | Что внутри |
|---|---|
| `apple_tracks.npy` | `[50, 100, 2]` float32, координаты (x, y) в пикселях кадра 1296×720 |
| `apple_visibility.npy` | `[50, 100]` bool |
| `apple_summary.png` | «первый кадр с точками \| последний кадр с траекториями» — для сравнения на глаз с `results/tests/e2e_apple/summary.png` |
| `apple_meta.json` | sha256 видео и чекпоинта, версия torch, число потоков, процессор, дата |

Тест считает среднее расстояние между текущими и эталонными треками по точкам,
видимым в обоих прогонах, и требует меньше 0.5 px; видимость должна совпадать
не меньше чем в 98% случаев. На той же машине повторный прогон даёт побитово
одинаковые треки; допуск нужен для других процессоров.

Пересоздать эталон (например, после смены версии torch):

```bash
bash run.sh --make-reference
```
